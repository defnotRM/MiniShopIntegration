# MiniShop - Web Application

โปรเจกต์พัฒนาระบบร้านค้าออนไลน์ด้วย Vite + Vanilla JavaScript + Tailwind CSS

## การติดตั้งและเริ่มใช้งาน

1. ติดตั้ง dependencies:
```bash
npm install
```

2. รันเซิร์ฟเวอร์สำหรับพัฒนา:
```bash
npm run dev
```

3. เข้าใช้งานผ่านเบราว์เซอร์:
`http://localhost:5173/`

## โครงสร้างและส่วนประกอบของระบบ

- **Dashboard**: แสดงการ์ดสถิติ Total Products, Orders, Revenue และตาราง Recent Orders
- **Products**: แสดงรายการสินค้า ระบบค้นหา ตัวกรองหมวดหมู่ และการเพิ่มสินค้าลงตะกร้า
- **Profile**: แสดงข้อมูลโปรไฟล์ผู้ใช้งาน และสรุปสถิติบัญชี (Account Summary)
